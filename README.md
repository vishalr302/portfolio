# Portfolio template

A dependency-free, responsive portfolio with three pages:

- `index.html` — home and featured projects
- `about.html` — biography, services, and experience
- `portfolio.html` — three detailed project case studies with pipelines, impact, testing, and brief links
- `styles.css` — all visual styles and responsive rules
- `project-briefs/` — downloadable one-page briefs for the three featured projects

## Customize it

1. Search all files for `Your Name`, `Your City`, `hello@example.com`, and `your-username`.
2. Replace each `example.com/project-*` URL with a live project, repository, or case study.
3. Replace a `.project-art` placeholder with an image if you want. For example:

   ```html
   <a class="project-art" href="YOUR_PROJECT_URL">
     <img src="images/project-one.jpg" alt="Short description of the project">
   </a>
   ```

4. Edit the skill labels, biography, experience, and project descriptions.
5. Open `index.html` in a browser to preview the site.

No build command or framework is required.

The project case studies use repository README material where available. The Grant Intelligence repository is public; the NFL repository URL is recorded locally but is not currently public, and the Wildfire project does not yet have a published project repository.
